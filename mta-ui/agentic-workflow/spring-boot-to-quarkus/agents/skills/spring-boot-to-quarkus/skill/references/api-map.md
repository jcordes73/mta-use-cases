# API Map — Spring Boot 3.x to Quarkus 3.x

| old_api | new_api | kind | action | before | after | notes | source_section |
|---|---|---|---|---|---|---|---|
| org.springframework.boot.SpringApplication | io.quarkus.runtime.Quarkus | class | replace | `SpringApplication.run(MyApp.class, args);` | `Quarkus.run(args);` | Remove `@SpringBootApplication` class or replace with `@QuarkusMain` | Application Entry Point |
| org.springframework.boot.autoconfigure.SpringBootApplication | removed | annotation | remove | `@SpringBootApplication` | (remove — Quarkus discovers beans automatically via CDI) | No equivalent needed; Quarkus uses build-time bean discovery | Application Entry Point |
| org.springframework.beans.factory.annotation.Autowired | jakarta.inject.Inject | annotation | replace | `@Autowired` | `@Inject` | Constructor injection preferred in both frameworks | Dependency Injection |
| org.springframework.stereotype.Component | jakarta.enterprise.context.ApplicationScoped | annotation | replace | `@Component` | `@ApplicationScoped` | Use `quarkus-spring-di` for compatibility or migrate to CDI | Dependency Injection |
| org.springframework.stereotype.Service | jakarta.enterprise.context.ApplicationScoped | annotation | replace | `@Service` | `@ApplicationScoped` | CDI has no `@Service` stereotype; use scope annotation directly | Dependency Injection |
| org.springframework.stereotype.Repository | jakarta.enterprise.context.ApplicationScoped | annotation | replace | `@Repository` | `@ApplicationScoped` | Exception translation not automatic; use Panache for data access | Dependency Injection |
| org.springframework.context.annotation.Configuration | jakarta.enterprise.context.ApplicationScoped | annotation | replace | `@Configuration` | `@ApplicationScoped` | `@Bean` methods become `@Produces` methods | Dependency Injection |
| org.springframework.context.annotation.Bean | jakarta.enterprise.inject.Produces | annotation | replace | `@Bean` | `@Produces` | Method return type determines the bean type | Dependency Injection |
| org.springframework.beans.factory.annotation.Qualifier | jakarta.inject.Named | annotation | replace | `@Qualifier("myBean")` | `@Named("myBean")` | Or create a custom CDI qualifier annotation | Dependency Injection |

| org.springframework.boot.context.properties.ConfigurationProperties | io.smallrye.config.ConfigMapping | annotation | replace | `@ConfigurationProperties(prefix = "app")` | `@ConfigMapping(prefix = "app")` | Interface-based in Quarkus; class-based binding not supported with `@ConfigMapping` | Configuration |

| org.springframework.web.bind.annotation.GetMapping | jakarta.ws.rs.GET | annotation | replace | `@GetMapping("/items")` | `@GET @Path("/items")` | Combine `@GET` with `@Path` for method-level mapping | Web / REST |
| org.springframework.web.bind.annotation.PostMapping | jakarta.ws.rs.POST | annotation | replace | `@PostMapping("/items")` | `@POST @Path("/items")` | Combine `@POST` with `@Path` | Web / REST |
| org.springframework.web.bind.annotation.PutMapping | jakarta.ws.rs.PUT | annotation | replace | `@PutMapping("/items/{id}")` | `@PUT @Path("/items/{id}")` | Combine `@PUT` with `@Path` | Web / REST |
| org.springframework.web.bind.annotation.DeleteMapping | jakarta.ws.rs.DELETE | annotation | replace | `@DeleteMapping("/items/{id}")` | `@DELETE @Path("/items/{id}")` | Combine `@DELETE` with `@Path` | Web / REST |
| org.springframework.web.bind.annotation.PathVariable | jakarta.ws.rs.PathParam | annotation | replace | `@PathVariable String id` | `@PathParam("id") String id` | Parameter name must be explicit in JAX-RS | Web / REST |
| org.springframework.web.bind.annotation.RequestParam | jakarta.ws.rs.QueryParam | annotation | replace | `@RequestParam String name` | `@QueryParam("name") String name` | Parameter name must be explicit in JAX-RS | Web / REST |

| org.springframework.web.bind.annotation.RequestBody | removed | annotation | remove | `@RequestBody MyDto dto` | `MyDto dto` | JAX-RS deserializes body parameters automatically (no annotation needed) | Web / REST |
| org.springframework.web.bind.annotation.ResponseBody | jakarta.ws.rs.Produces | annotation | replace | `@ResponseBody` | `@Produces(MediaType.APPLICATION_JSON)` | In JAX-RS, use `@Produces` on class or method to set response content type | Web / REST |
| org.springframework.http.ResponseEntity | jakarta.ws.rs.core.Response | class | replace | `return ResponseEntity.ok(data);` | `return Response.ok(data).build();` | `Response.status(404).build()` for error responses | Web / REST |
| org.springframework.web.bind.annotation.ExceptionHandler | jakarta.ws.rs.ext.ExceptionMapper | annotation | replace | `@ExceptionHandler(MyException.class)` | `implements ExceptionMapper<MyException>` | Implement `ExceptionMapper<T>` interface as a `@Provider` bean | Web / REST |
| org.springframework.web.bind.annotation.ControllerAdvice | removed | annotation | remove | `@ControllerAdvice` | (use `@Provider` on `ExceptionMapper` implementations) | No central exception handler; each exception type gets its own `ExceptionMapper` | Web / REST |

| org.springframework.stereotype.Controller | jakarta.ws.rs.Path | annotation | replace | `@Controller` | `@Path("/")` | For Qute templates, add `@io.quarkus.qute.Template` injection | Thymeleaf to Qute Migration |
