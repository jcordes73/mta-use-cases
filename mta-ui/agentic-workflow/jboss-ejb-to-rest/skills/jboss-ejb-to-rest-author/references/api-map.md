# API Map

Each row is an API element that changes between the EJB-remoting world and the
REST world. Process rows in `kind` order: package → class → annotation →
interface → enum → method → field.

| old_api | new_api | kind | action | before | after | notes | source_section |
|---|---|---|---|---|---|---|---|
| `jakarta.ejb.Remote` business interface (consumer-side usage) | generated/`@RegisterRestClient` client interface from the OpenAPI document | interface | replace | `@EJB(lookup = "ejb:customer-app/customer-ejb/CustomerServiceBean!com.acme.customer.CustomerServiceRemote")\nprivate CustomerServiceRemote customerService;` | `@Inject\n@RestClient\nprivate CustomerServiceClient customerService;` | Provider-side `@Remote` interface is **kept** (§4.4) — only the consumer's usage changes | §3.1, §3.2 |
| `jakarta.ejb.Remote` business interface (provider-side exposure) | kept + new JAX-RS resource calling the local view | interface | replace | `@Remote public interface CustomerServiceRemote { ... }` (only entry) | `@Path("/api/v1/customers") public class CustomerResource { @EJB private CustomerServiceLocal customerService; ... }` | Additive: REST offered in addition; remote interface never removed (§4.4) | §2.1, §2.2 |
| `javax.naming.InitialContext.lookup("ejb:...")` | MP REST Client (CDI) or programmatic `RestClientBuilder` | method | replace | `Context ctx = new InitialContext();\nCustomerServiceRemote svc = (CustomerServiceRemote) ctx.lookup("ejb:...");` | `CustomerServiceClient client = RestClientBuilder.newBuilder()\n  .baseUri(URI.create("http://customer-app:8080"))\n  .register(CustomerNotFoundResponseExceptionMapper.class)\n  .build(CustomerServiceClient.class);` | Programmatic builder is the base-EAP (no XP) fallback — CDI `@Inject @RestClient` fails there with WELD-001408 | §3.3, §3.4, §3.2 |
| `jakarta.xml.ws.WebServiceRef` (consumer) | `@Inject @RestClient` client (optional, per call site) | annotation | replace | `@WebServiceRef(wsdlLocation = "http://customer-app:8080/CustomerServiceService?wsdl")\nprivate CustomerServiceService service;` | `@Inject @RestClient private CustomerServiceClient customerService;` | Migration is optional and gradual for SOAP clients; delete generated stub sources + `wsdlLocation` wiring only for migrated call sites | §3.2 (JAX-WS variant) |
| `jakarta.ws.rs.ext.ExceptionMapper` (used on the REST **client** side) | `org.eclipse.microprofile.rest.client.ext.ResponseExceptionMapper` | interface | replace | `class X implements ExceptionMapper<CustomerNotFoundException>` (registered on client) | `class X implements ResponseExceptionMapper<CustomerNotFoundException> { handles(int, MultivaluedMap) ...; toThrowable(Response) ...; }` | Server-side ExceptionMapper has no effect on a REST client; MP method is `toThrowable`, not `throwable` (compile-verified) | §3.2, §10.1 |
| `jakarta.ejb.Asynchronous` `Future<T>`/`CompletionStage<T>` remote method | `POST .../jobs` → `202 Accepted` + status URL; consumer polls status resource (polling wrapped in the adapter) | method | replace | `@Asynchronous public Future<T> startX(long id)` | `@POST @Path("/{id}/jobs") public Response startX(...) { return Response.accepted().location(statusUri).build(); }` | Do not let the consumer block indefinitely; alternatives: callback/webhook or sync-with-timeout | §5.7 |
| shared remote-interface DTO classes (`*-api` jar types) | generated model classes (`<pkg>.model.*`) from the OpenAPI document | class | replace | `import com.acme.customer.api.CustomerDTO;` | `import com.acme.customer.model.CustomerDTO;` | DTO provenance: consumer-owned, generated at build time; provider can evolve its DTOs behind a stable API. Keep shared jar available for consumers that never migrate | §3.7, §3.2 |
| DTO types embedding `javax.persistence.*` (lazy fields, entities) | dedicated JSON-friendly REST DTOs | class | replace | entity types leaking into remote interface signatures | dedicated REST DTOs: default constructor, public getters/setters, no persistence types | If DTOs are shared types inside entity classes, introduce dedicated REST DTOs | §2.3 |
| `javax.xml.ws.*` / `javax.jws.*` SOAP endpoint + stubs | `jakarta.xml.ws.*` (EAP 8 `wsconsume` generates jakarta stubs) | package | move_package | `import javax.xml.ws.WebServiceRef;` | `import jakarta.xml.ws.WebServiceRef;` | `javax.xml.ws` clients only work against a server still on the `javax` namespace; on the jakarta target, regenerate stubs | §2.6 |
